## 🛠️ Tech Stack & Highlights

- **Frontend:** React, TypeScript, JavaScript (ES6+), Vite, Tailwind CSS, HTML5, CSS3, Webflow
- **Backend & Relational DBs:** Node.js, Express.js, PostgreSQL, MySQL, REST APIs, Sequelize ORM
- **AI & Automation:** Google Gemini API, Multi-Model Failovers, AI Agents
- **Performance & DevOps:** Sub-second LCP, Brotli/Gzip Pre-compression, Edge Caching, Git & GitHub

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/ahadaliwazir/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
